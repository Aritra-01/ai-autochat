# Prompt packs

Short, friendly prompts for **AI Autochat → Messages & options → Custom messages**.
Paste one prompt per line. Blank lines are ignored. The extension uses the first
200 lines, up to 1,000 characters each.

These packs are intentionally simple. The goal is a conversation that keeps
moving, not a benchmark.

## Writing your own

A good autochat prompt is:

- **Short** — one sentence, easy to answer.
- **Open** — leaves room for a reply instead of yes/no.
- **Gentle** — no arguments, personal data, or work for the model.
- **Repeatable** — still makes sense after ten turns.

Avoid prompts that ask for medical, legal, or financial advice, or that try to
jailbreak a provider. The extension is meant for light conversation.
