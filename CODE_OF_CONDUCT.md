# Code of Conduct

## The short version

Be kind. Assume good faith. Make room for people who are learning.

This project is a small open-source experiment. It is not a place for
harassment, gatekeeping, or arguments about which AI provider is “best.”

## Expected behavior

- Use welcoming and inclusive language.
- Respect differing viewpoints and experiences.
- Give and accept constructive feedback gracefully.
- Credit other people's work.
- Keep discussion focused on the project.

## Unacceptable behavior

- Harassment, intimidation, or discrimination in any form.
- Sexualized language or imagery, or unwelcome attention.
- Trolling, insulting comments, or personal attacks.
- Publishing someone's private information without permission.
- Spamming issues or pull requests with low-effort or automated content.
- Encouraging use of the project to harass people, evade rate limits, or break
  a provider's terms.

## Scope

This code applies to the repository, issues, pull requests, discussions, and any
other project space. It also applies when representing the project elsewhere.

## Enforcement

Maintainers may remove comments, close issues or pull requests, or block
accounts that violate this code. Reports can be sent privately through the
repository's **Security → Report a vulnerability** flow or by contacting the
maintainer on GitHub.

## Attribution

This is a short, project-specific code of conduct informed by the
